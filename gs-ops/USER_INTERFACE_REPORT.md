### 3. 用户 Store (`stores/user.js`)

#### State
```javascript
{
  currentUser: null,        // 当前登录用户
  permissions: [],          // 用户权限列表
  isAuthenticated: false,   // 是否已认证
  loading: false            // 加载状态
}
```

#### Getters
- ✅ `isAdmin` - 是否管理员
- ✅ `isOperator` - 是否操作员
- ✅ `isViewer` - 是否查看者
- ✅ `hasPermission(permission)` - 检查单个权限
- ✅ `hasAnyPermission(...permissions)` - 检查任一权限
- ✅ `hasAllPermissions(...permissions)` - 检查所有权限

#### Actions
- ✅ `login(username, password)` - 登录
- ✅ `logout()` - 登出
- ✅ `fetchCurrentUser()` - 获取当前用户
- ✅ `fetchPermissions()` - 获取权限列表
- ✅ `changePassword(old, new)` - 修改密码
- ✅ `initialize()` - 初始化（页面加载时恢复登录状态）

### 4. 路由系统

#### 路由配置

| 路径 | 组件 | 认证 | 权限 |
|------|------|------|------|
| `/login` | Login | 否 | - |
| `/` | Dashboard | 是 | - |
| `/services` | ServiceList | 是 | - |
| `/services/:id` | ServiceDetail | 是 | - |
| `/logs` | Logs | 是 | - |
| `/users` | UserManagement | 是 | `users:manage` |
| `/settings` | Settings | 是 | - |

#### 路由守卫

**功能**:
- ✅ 未登录自动跳转 `/login`
- ✅ 已登录访问 `/login` 自动跳转首页
- ✅ 权限检查，无权限提示并跳转
- ✅ Token 过期自动刷新
- ✅ 刷新失败自动跳转登录

**流程**:
```
1. 检查路由是否需要认证
2. 未登录 → 尝试从 Token 恢复
3. 恢复失败 → 跳转登录页
4. 已登录 → 检查权限要求
5. 无权限 → 提示并跳转首页
6. 有权限 → 允许访问
```

## 📊 使用指南

### 访问方式

1. **启动服务**
```bash
cd gs-ops/backend
gs run
```

2. **访问地址**
- 前端: http://127.0.0.1:7310/
- API: http://127.0.0.1:7310/api/

### 登录

**默认账户**:
- 管理员: `admin` / `Admin123`
- 操作员: `operator1` / `Operator123!`
- 查看者: `viewer1` / `Viewer123!`

### 用户管理

1. 以管理员身份登录
2. 点击左侧菜单 "用户管理"
3. 点击 "+ 创建用户" 创建新用户
4. 点击 "编辑" 修改用户信息
5. 点击 "重置密码" 重置用户密码
6. 点击 "删除" 删除用户

### 权限说明

**管理员**:
- ✅ 访问所有页面
- ✅ 管理用户
- ✅ 所有操作权限

**操作员**:
- ✅ 访问仪表盘、服务管理、日志、监控
- ❌ 不能访问用户管理
- ✅ 可以操作服务

**查看者**:
- ✅ 访问仪表盘、服务管理、日志、监控
- ❌ 不能访问用户管理
- ❌ 只能查看，不能操作
