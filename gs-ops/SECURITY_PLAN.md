# GS-OPS v0.4.0 - 安全加固实施计划

## 📋 安全加固清单

### 1. 密码安全
- [x] 密码强度验证（已实现）
- [x] PBKDF2 加密存储（已实现）
- [ ] 密码历史记录（防止重复使用）
- [ ] 密码过期策略
- [ ] 首次登录强制修改密码

### 2. 登录安全
- [ ] 登录失败次数限制
- [ ] 账户临时锁定
- [ ] 登录日志记录
- [ ] 可疑登录检测（IP/设备变化）

### 3. Session 安全
- [x] JWT Token 过期时间（已实现：24小时）

- [ ] Token 黑名单（登出后失效）
- [ ] 单点登录（强制登出其他会话）
- [ ] Session 过期提醒

### 4. API 安全
- [ ] 请求频率限制（Rate Limiting）
- [ ] IP 白名单/黑名单
- [ ] API 访问日志
- [ ] 敏感操作审计日志

### 5. 数据安全
- [ ] 数据库备份定时任务
- [ ] 敏感数据脱敏（日志中）
- [ ] 配置文件权限检查

### 6. 输入安全
- [x] 前端输入验证（已实现）

- [ ] SQL 注入防护检查

### 7. 网络安全

- [ ] 安全响应头
