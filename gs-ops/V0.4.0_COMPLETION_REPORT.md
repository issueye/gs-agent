## 🔧 技术实现细节

### 架构调整

1. **响应格式统一**
   - 使用 `res.send()` 替代 `res.json()`
   - 统一的响应包装器（`ok()`, `created()`, `fail()`）

2. **请求处理修复**
   - `req.body` 属性（非函数调用）
   - `req.headers["authorization"]` 获取请求头
   - `req.params` 获取路由参数

3. **Base64 编码**
   - 使用 GTS 标准库 `@std/encoding/base64`
   - URL 安全的 Base64 编码（`encodeURL()`, `decodeURL()`）

### 遇到的问题与解决

#### 问题 1: crypto.base64Encode 不存在
**原因**: GTS crypto 模块不提供 Base64 编码  
**解决**: 使用 `@std/encoding/base64` 模块

#### 问题 2: req.body() 报错
**原因**: GTS web 中 `req.body` 是属性而非方法  
**解决**: 将所有 `req.body()` 改为 `req.body`

#### 问题 3: req.header() 不是函数
**原因**: GTS 使用 `req.headers` 对象访问请求头  
**解决**: 使用 `req.headers["authorization"]`

#### 问题 4: HTTP 头大小写问题
**原因**: 浏览器发送 `Authorization`，但可能被转为小写  
**解决**: 同时检查 `authorization` 和 `Authorization`

#### 问题 5: res.json() 返回空响应
**原因**: 需要使用 `res.send()` 发送 JSON 字符串  
**解决**: 
```javascript
res.setHeader("Content-Type", "application/json");
return res.send(JSON.stringify(data));
```

#### 问题 6: 认证中间件阻塞所有请求
**原因**: `req.path()` 调用错误，应使用 `req.path` 属性  
**解决**: 改为 `let path = req.path || req.url || ""`
